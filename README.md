# Pannatorn Kulnara — Portfolio

A standalone, responsive portfolio remake. Open `index.html` directly or serve this directory with a static web server, such as:

The published site is hosted with GitHub Pages from the `main` branch.

```sh
python -m http.server 8765
```

Then visit `http://localhost:8765`.

The original photos and logo are stored locally in `assets/`. The site features one gaming edit and links to all nine YouTube samples from the original site. Video thumbnails and the Google Fonts stylesheet need an internet connection.
